Web Annotator

Build a W3C Web Annotation by filling in the form. The live preview shows the JSON-LD 1.1 object that will be saved to RERUM.

Annotation Fields

The plain-text content of the annotation (body.value → rdf:value). URI of the resource being annotated (target → oa:hasTarget). Reason for the annotation (motivation → oa:motivatedBy). BCP47 language tag for the body text (body.language → dc:language).
Fill in Body Text and Target URI to enable saving.
