Web Annotator

A Web Annotation is a way to attach a comment, tag, or description to any resource on the web — a web page, image, video, or document — using its URI. Annotations are expressed as JSON-LD, a format that links your data to shared vocabularies so machines can understand it too.

Fill in the form below to build your own annotation. When you are happy with the preview, you can save it to RERUM (a Linked Open Data store) or download it as a file.
